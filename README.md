# Ключник

Локальный кабинет для сбора семантики и подготовки поисковой кампании. Сбор и оценка релевантности выполняются в n8n.

## Запуск на Windows

1. Скачайте репозиторий через **Code → Download ZIP**, распакуйте в одну папку. Для запуска нужен Node.js 22 или новее.
2. Запустите локальный n8n с исходным агентом Wordstat и запустите `start.cmd`. Кабинет доступен по адресу [127.0.0.1:8787](http://127.0.0.1:8787). Если браузер открылся раньше запуска Node.js, обновите страницу.
3. В кабинете нажмите **«Подключить n8n»**. Укажите адрес n8n, его API-ключ и точное имя воркфлоу. Начальное значение имени — `Kluchnik`. Создание ключа описано в [документации n8n](https://docs.n8n.io/api/authentication/).
4. Если исходный агент запрашивает Folder ID при каждом запуске, «Ключник» предложит ввести его один раз при подключении.
5. Нажмите **«Собрать семантику»**. Для проекта с заданным регионом потребуется числовой код Wordstat. В кабинете появятся пять CSV. На кластеризацию идёт `05_final_clean.csv`.

## Подключение

Поддерживается локальный Wordstat-агент из исходного проекта с настроенным ключом Wordstat в узле сбора и credential Anthropic в узле Claude. У API-ключа n8n должны быть права чтения, создания и активации воркфлоу и создания credential вебхука. Рабочая копия должна иметь доступ к credential Anthropic исходного агента. n8n должен быть доступен с того же компьютера, на котором запущен «Ключник».

«Ключник» находит воркфлоу по точному имени, создаёт в n8n отдельную интеграционную копию, переиспользует настройки Wordstat и credential Claude и настраивает защищённый вебхук. Исходный воркфлоу можно запускать отдельно привычным способом. Ручной импорт JSON для этого сценария не требуется.

Ключ API n8n используется во время подключения и не сохраняется. Адрес и токен вебхука сохраняются локально в `%LOCALAPPDATA%\Kluchnik\n8n.json`. Воркфлоу в репозитории содержит заглушки вместо ключей. Панель кампаний поддерживает демонстрационную передачу в Яндекс Директ.
