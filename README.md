# Ключник

Локальный кабинет для сбора семантики и подготовки поисковой кампании. Сбор и оценка релевантности выполняются в n8n.

## Установка на Windows

Запустите `Kluchnik-Setup.exe` для Windows x64. Node.js входит в установщик. Откройте **«Ключник»** из меню «Пуск». Кабинет доступен по адресу [127.0.0.1:8787](http://127.0.0.1:8787).

Чтобы запустить исходники без установщика, распакуйте репозиторий и откройте `start.cmd` с установленным Node.js 22 или новее. Перед обновлением через установщик закройте окно запущенного «Ключника». Хранилище проектов привязано к браузеру и локальному адресу, подключения хранятся отдельно от файлов приложения.

## Подключения

Откройте **«Подключения»** в боковом меню.

- **n8n.** Запустите свой локальный n8n и укажите адрес, API-ключ и точное имя исходного воркфлоу Wordstat. Folder ID потребуется, если исходный агент запрашивает его при запуске. Создание ключа описано в [документации n8n](https://docs.n8n.io/api/authentication/).
- **Яндекс Директ.** Введите OAuth-токен приложения с доступом к API Директа. Поле логина клиента заполняйте, если работаете от имени клиента агентства. Доступ проверяется чтением кампаний. На Windows токен хранится с шифрованием для текущего пользователя Windows. [Авторизация в API Директа](https://yandex.ru/dev/direct/doc/ru/format).

Поддерживается локальный Wordstat-агент из исходного проекта с настроенным ключом Wordstat в узле сбора и credential Anthropic в узле Claude. У API-ключа n8n должны быть права чтения, создания и активации воркфлоу и создания credential вебхука. Рабочая копия должна иметь доступ к credential Anthropic исходного агента. n8n должен быть доступен с того же компьютера, на котором запущен «Ключник».

«Ключник» находит воркфлоу по точному имени, создаёт в n8n отдельную интеграционную копию, переиспользует настройки Wordstat и credential Claude и настраивает защищённый вебхук. Исходный воркфлоу можно запускать отдельно привычным способом. Ручной импорт JSON для этого сценария не требуется.

Ключ API n8n используется во время подключения и не сохраняется. Адрес и токен вебхука сохраняются локально в `%LOCALAPPDATA%\Kluchnik\n8n.json`. Воркфлоу в репозитории содержит заглушки вместо ключей.

## Шаблоны кампаний

Откройте **«Шаблоны» → «Создать шаблон»** и задайте собственный набор настроек уровня кампании. При подготовке черновика выберите его по имени или напишите в пожеланиях «Используй шаблон «Имя шаблона»». Применённые настройки копируются в черновик. Последующее редактирование шаблона повлияет на черновик после повторного применения.

В разделе **«Яндекс Метрика и цели»** укажите ID счётчиков и OAuth-токен с доступом на чтение, затем нажмите **«Обновить цели»**. Выберите цели и при необходимости укажите цену каждой. Кнопка обновляет список по запросу. Скрытого фонового обмена и сохранения OAuth-токена нет. Схема проверки комбинаций стратегий и целей предварительная.

Пакет кампании содержит сохранённые настройки уровня кампании и выбранные цели.

### Шаблоны групп

В разделе **«Шаблоны»** создайте нужные шаблоны групп. После кластеризации нажмите **«Подготовить кампанию»**, выберите шаблон кампании, затем укажите шаблон для каждой группы. В готовом черновике назначение можно поменять через **«Шаблон группы»**.

Ключевые фразы из кластера дополняются фразами шаблона группы. Собственные минус-фразы группы объединяются с минус-фразами её шаблона, общие минус-фразы кампании хранятся отдельно. Регион проекта используется по умолчанию. В шаблоне группы можно явно выбрать регионы или задать зоны координатами и радиусом.

Настройки группы сохраняются в черновике и в пакете кампании.

## Подготовка и передача кампании

Соберите семантику через n8n или импортируйте пять CSV. Кластеризация берёт фразы из `05_final_clean.csv`. Выберите шаблон кампании и шаблоны для групп. В черновике проверьте ключевые фразы, минус-фразы, объявления и посадочные ссылки.

Нажмите **«Проверить для Директа»**, затем подтвердите черновик. Для прямой передачи сейчас поддерживается поисковая ЕПК с недельным бюджетом и обычной стратегией «Максимум кликов» или «Максимум конверсий» с одной целью. Если указано гео, Директу передаются числовые ID регионов. Несопоставленные параметры останавливают отправку с объяснением до создания кампании.

После отдельного подтверждения передачи приложение создаёт кампанию, группы, фразы и комбинаторные объявления и показывает ID кампании. Модерацию и запуск выполняет пользователь в Директе. При частичном сбое приложение сохраняет ID уже созданной кампании и не повторяет создание по той же операции. Без подключения Директа доступна демопередача.

## Сборка установщика

Поместите файлы приложения, Windows x64 `node.exe` из дистрибутива Node.js 22 и его `LICENSE` под именем `NODE-LICENSE.txt` в отдельную папку. Выполните `makensis -DINPUT=/path/to/staging -DOUTPUT=/path/to/Kluchnik-Setup.exe installer/Kluchnik.nsi`.
